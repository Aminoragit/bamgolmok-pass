# 밤골목 패스 (Bamgolmok Pass) — 프로토타입

Dopamine Seoul 24 (서울 야간경제 활성화 해커톤) 예선 기획안 「밤골목 패스」(주제 01 골목 연결)의 작동 MVP 프로토타입입니다.
**시연용 프로토타입**이며, 실사용자·성과 데이터는 없습니다.

행사 끝난 밤, 메가이벤트 관람객을 반경 1km 골목 식당으로 이끄는 라스트오더 알림 서비스입니다.

## 핵심 기능 (실제 동작)

- **행사 종료 카운트다운**: 서울라이트 DDP 종료 시각 21:30 기준 카운트다운. 종료 30분 전부터 '알림 활성' 상태로 전환되는 로직이 실제로 동작합니다. 화면의 '시연용 시각 이동' 버튼으로 상태 전환을 언제든 확인할 수 있습니다.
- **골목 점포 목록**: DDP 반경 1km 표본 점포 4곳. 혼잡도 필터(여유/보통 이하)와 정렬(라스트오더 임박순/가까운순), 라스트오더까지 남은 시간이 실시간으로 계산됩니다.
- **QR 스탬프 → 야간 바우처**: 카메라 없이 스탬프 코드 입력 또는 '방문 인증 시뮬레이션' 버튼으로 적립 → 바우처 발급까지 클라이언트에서 끝까지 시연할 수 있습니다 (시연용 표기). 실제 서비스에서는 점주 확인 없이는 발급되지 않는 인간 승인 게이트를 둡니다.

## 실행 방법

정적 웹앱입니다. 빌드 도구가 필요 없습니다.

```bash
# 저장소를 받은 뒤
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (fetch를 쓰므로 file:// 직접 열기는 안 됩니다)
```

GitHub Pages로도 배포돼 있습니다 (저장소 Settings의 Pages 주소 참조).

## 데이터 출처와 표본 고지

- **검증된 사실 (2026-11-26 현장 검증)**: 서울라이트 DDP 2025 겨울 회차 12/18~31, 운영 18:00~21:30 (서울시 공식 보도자료, 서울디자인재단 주관). 점포 4곳(테라스시·만족오향족발 동대문점·낙지형님·아스론가)의 점포명과 라스트오더 시각(21:10~23:00)은 실존을 확인한 표본입니다.
- **예시 데이터**: 여유 좌석 수, 점포별 혼잡도 표시값, 거리 수치는 예시입니다. 화면에도 '예시'라고 표시했습니다.
- **혼잡도 구조**: `data.json`은 서울시 실시간 도시데이터(OA-21285)의 응답 구조를 본뜬 로컬 대체 데이터입니다. 혼잡도 4단계(여유·보통·약간 붐빔·붐빔)는 실제 데이터셋 정의와 같습니다. 실제 API 연동 지점은 `index.html`의 `loadCityData()`와 코드 주석에 분리해 뒀습니다.
- **야간 매출 필드**: 서울시 상권분석서비스(추정매출-상권)에 21~24시 매출 필드 `TMZON_21_24_SELNG_AMT`가 실재함을 확인했습니다 (본선 연동 예정).

## 판정 원칙

추천·발급 판정은 결정적 규칙(혼잡도·거리·라스트오더 남은 시간)으로만 계산합니다. AI(LLM)는 추천 문구 생성에만 쓰는 설계이며, 이 프로토타입의 판정 로직에는 AI가 개입하지 않습니다.
